# flightbalance
> This project was created as a prototype for the FlightBalance Android app, [available here](https://play.google.com/store/apps/details?id=kristianseng.flightbalance).

FlightBalance is a C# application designed to let you perform weight and balance calculations for GA aircraft while simultaneously viewing the results. You can fine-tune aircraft profiles by adding load stations/envelope limits and calculation results are shown on a real-time chart.
